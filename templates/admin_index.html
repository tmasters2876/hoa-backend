Help & Reference

Browse & Filters

Filter clauses by keyword (searches clause_id, citation, document, summary, and full text), document, or tag. Results are paginated at 25 per page. Active filters persist across page turns.

Add Clause

Manually insert a single new clause. At least one of clause_text or plain_summary is required. The embedding is not generated automatically — use Regenerate Embedding on the saved clause afterward.

Import CSV — Add

Bulk-inserts clauses from a .csv file. Column rules:

  • At least one of clause_text or plain_summary must be non-empty per row
  • page and precedence_level must be whole numbers if provided
  • tags — comma-separated, e.g. fence, arc
  • match_source defaults to CSV Import if omitted
  • Columns not in the template are rejected; valid rows are inserted even if others fail

All imported clauses start with stale embeddings and won't appear in semantic search until regenerated.

Import CSV — Delete

Permanently deletes every Supabase row whose clause_id matches a value in the file. There is no undo. The CSV must contain a clause_id column; all other columns are ignored. Rows with an empty clause_id are skipped.

Embeddings

Each clause has an embedding — a numeric vector used for semantic search by the HOA chatbot.

  • Editing clause_text or plain_summary nulls the embedding (marks it stale), because the old vector no longer reflects the new text.
  • Stale clauses are excluded from vector search results until regenerated.
  • Use Regenerate Embedding on any clause to call OpenAI and refresh it.
  • Model in use: {{ embedding_model }}

Search Test

Runs a live query using the same embedding model and Supabase match_clauses RPC as the production chatbot. Use this to verify that a question surfaces the expected clauses before testing in the frontend.
